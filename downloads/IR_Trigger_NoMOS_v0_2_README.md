# ИК-канал ЛКМ без MOSFET — v0.2

Вариант прямого подключения для ATtiny85, KP-2012F3C и KY-032.
Это схема для проверки и сборки после измерения сигнала ЛКМ.
Физические площадки на плате Logitech G Pro X Superlight 2 DEX ещё не определены.
Схема не испытывалась на железе. Готовые ИК-прошивки передатчика / приёмника
в этот комплект не входят; рабочая RecoilEngine R4.5 здесь не изменяется.

## Что докупить

| Деталь | Количество | Для чего |
|---|---:|---|
| Резистор 10 кОм | 2 | R0 между RESET и VCC; R1 последовательно во вход ЛКМ |
| Резистор 470 Ом | 1 | R2, ограничение тока ИК-светодиода при прямом управлении |
| Переходник SOIC8 → DIP8 под фактический корпус | При необходимости | Если выпаянный ATtiny — SMD, а использовать хочешь DIP8-панель |
| Тонкий изолированный провод, монтажная плата, изоляция | По наличию | Механический монтаж и соединения |

Вместо покупки R2 470 Ом можно использовать **шесть резисторов по 82 Ом
последовательно: 6 × 82 = 492 Ом**. Один резистор 82 Ом в это место не подходит.
Для 10 кОм сборка из 82-омных резисторов непрактична.

ATtiny85, DIP8-панель, KP-2012F3C, KY-032 уже есть по твоему списку.
Конденсаторы тоже есть: требуется по две штуки 0,1 мкФ и 4,7 мкФ
(пара у передатчика, пара у приёмника). Для этого варианта 0,01 мкФ не нужен.
Резисторы 10 кОм и 470 Ом подойдут обычные 0,125 Вт или SMD 0805/1206.
Конденсаторы брать с допустимым напряжением не менее 6,3 В.
Керамические MLCC неполярные; если 4,7 мкФ полярные — соблюдать полярность.

Не покупать SOIC-переходник наугад: у ATtiny85-20SU бывает широкий корпус
около 208 mil, который не соответствует узкому SOIC8. Проверить свой чип.
Если сам ATtiny в DIP8, переходник не нужен.

Если питание берётся прямо с аккумулятора, а отдельной отключаемой линии нет,
для выключения передатчика понадобится миниатюрный выключатель питания
либо отдельное решение по согласованному выключению.
На аккумуляторе напряжение остаётся при OFF штатной мыши.
Не считать неизвестную логическую линию питания подходящей для передатчика.

MOSFET, 10 МОм, 47 кОм, 100 кОм и резистор затвора из предыдущей схемы
для этого варианта не нужны.
Если измерения покажут несовместимые уровни, потребуется пересмотр входа;
этот вопрос пока нельзя закрыть покупкой фиксированного набора деталей.

## Где что паять

Ножки ATtiny указаны физическими номерами. Смотреть на корпус сверху,
выемка / точка у ножки 1. GPIO ESP — номера сигналов, не места на гребёнке.
Одноимённые VTX и GND мыши внутри передатчика соединить.

| Контакт / деталь | Соединение |
|---|---|
| ATtiny pin 8, VCC | VTX: проверенное питание 3,0–4,2 В |
| ATtiny pin 4, GND | GND мыши |
| C1 0,1 мкФ | Между pin 8 и pin 4, максимально близко к корпусу |
| C2 4,7 мкФ | Параллельно C1 |
| ATtiny pin 1, RESET | Через R0 10 кОм к VTX; этот же вывод — ISP RESET |
| Сигнал штатной ЛКМ | Через R1 10 кОм к ATtiny pin 2 / PB3 |
| ATtiny pin 2 / PB3 | INPUT, без внутренней подтяжки |
| ATtiny pin 6 / PB1 | Через R2 470 Ом к A, аноду KP-2012F3C |
| K, катод KP-2012F3C | GND мыши |
| ATtiny pin 3 / PB4 | Не подключать |
| ATtiny pin 5 / PB0 | ISP MOSI |
| ATtiny pin 7 / PB2 | ISP SCK |

Полярность LED определить по даташиту корпуса / проверкой диодов.
Ориентировать излучатель на приёмник. ИК-свечение глазом не видно.
В этом варианте **анод питается от ножки PB1 через R2, а не от плюса АКБ**.
Приближённый расчёт тока с 470 Ом и Vf≈1,2 В:
при VTX 3,0–4,2 В получается 3,8–6,4 мА без учёта падения на выходе ATtiny.
Реальный ток будет зависеть от напряжения HIGH под нагрузкой.
Этого может хватить для 30 см прямой видимости, но связь нужно проверить
с конкретным приёмником и внешним освещением.

Таймер ATtiny должен выдавать пачки несущей около 38 кГц.
Постоянный HIGH на время удержания ЛКМ не заменяет ИК-протокол.

## Обязательная проверка входа ЛКМ

Сначала отсоединить старые провода ESP от мыши.
При снятом питании определить GND, затем при работающей мыши измерить SIG:
отпущенная ЛКМ / нажатая и удерживаемая ЛКМ.
Для прямого подключения нужны:

- напряжение SIG в пределах 0…VTX;
- HIGH выше гарантированного VIH и LOW ниже VIL из даташита ATtiny85
  при фактическом питании, с запасом на изменение заряда аккумулятора;
- подходящая временная форма сигнала; усреднённое показание мультиметра
  не доказывает отсутствие импульсов;
- согласованное питание: сигнал не должен подаваться на обесточенный ATtiny.

Условие «HIGH от 2,0 В» из прежней схемы с Q1 **не переносится**
на прямой вход. Например, совместимость сигнала 1,8 В с ATtiny,
питающимся от 4,2 В, нельзя предполагать.
R1 10 кОм ограничивает ток, но не повышает логический уровень.
INPUT_PULLUP здесь не включать: подтяжку сигнала обеспечивает штатная плата.
Если кнопка при нажатии замыкает SIG на GND, нажатие для ATtiny теперь LOW.
В прежнем варианте Q1 инвертировал его в HIGH; прошивка передатчика должна
соответствовать новой полярности.
При несовместимых уровнях прямое соединение не использовать:
потребуется согласование или иное подтверждённое питание ATtiny.
Пайку выполнять при отключённых аккумуляторе и USB.

## KY-032 → ESP

Показан вариант с подтверждённой работой KY-032 от 3,3 В:

| KY-032 | ESP32-S3 |
|---|---|
| + / VCC | 3V3 |
| GND | GND |
| OUT / S | GPIO5 |

C3 0,1 мкФ и C4 4,7 мкФ поставить параллельно между VCC и GND возле модуля.
Порядок контактов брать по надписям платы.
Собственный излучатель KY-032 нужно отключить, сохранив приёмник.
Действие EN / джампера зависит от конкретной версии модуля;
без её проверки соединение EN не назначено.
Нужно убедиться, что OUT подходит для приёма пачек внешнего ИК-передатчика.
KY-032 — отражательный датчик, пригодность для канала данных пока не испытана.

Если модулю нужны 5 В, прямое соединение его 5-вольтового OUT с ESP запрещено.
Для подтверждённого выхода 0/5 В возможен делитель:
OUT → 10 кОм → GPIO5, от GPIO5 20 кОм на GND ESP.
Реальные уровни проверить; для выхода 3,3 В этот делитель не использовать.
Эти дополнительные номиналы нужны только для такого 5-вольтового варианта,
поэтому в основной список покупок не включены.
Между мышью и ESP в рабочем режиме провод земли не прокладывается.

## ISP и состояние прошивок

Схема ISP и ESP32S3_ISP/ESP32S3_ISP.ino сохранены из v0.1 без изменений.
Подробный порядок — в ISP_INSTRUCTIONS.md, вторая страница PDF также включена.
На время ISP ATtiny полностью отсоединить от мыши, АКБ и LED;
питание цели только 3,3 В от ESP.
У выпаянного Digispark может быть отключён RESET: тогда обычный ISP не работает
и нужен отдельный HVSP. Сначала читать сигнатуру и сохранять fuse, не менять
их наугад. ESP напрямую 12 В не формирует и на свои GPIO их не допускает.

Переработка v0.2 касается электрической схемы.
ISP-скетч ранее собран на ESP32 core 2.0.17; повторно код не менялся.
Физических испытаний пока не было.
Для работы ИК-канала нужны отдельная прошивка ATtiny и декодер пакетов в ESP.
Нынешняя RecoilEngine R4.5 ожидает стабильный уровень GPIO5 с фильтром 3 мс.
