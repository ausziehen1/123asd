# RecoilEngine R4.3.0 — упрощённая настройка паттерна

Патч устанавливается поверх R4.2.0. Внутри только 10 новых/изменённых файлов
firmware/RecoilEngine и эта инструкция. Банки по 80 паттернов сохранены;
PatternBanks80.h и EngineeringConfig.h остаются из вашего проекта R4.2.

## Установка

1. Сохраните резервную копию всей папки проекта отдельно. Для возможности отката
   также экспортируйте прежние настройки JSON до загрузки новой версии.
2. Скопируйте 10 файлов из firmware/RecoilEngine/ архива в папку вашего скетча
   рядом с RecoilEngine.ino, подтвердив замену.
3. Уберите из папки скетча пять старых, больше не используемых заголовков:
   - ComputeTiming.h
   - MotionReport.h
   - TickMathCache.h
   - TickTimer.h
   - TraceCapture.h
   Их можно переместить в резервную копию. После удаления диагностика не имеет
   зависимостей от этих файлов; сама она уже удалена из исполняемого кода.
4. Если вы меняли пины/константы в старом .ino, перенесите собственные изменения.
   EngineeringConfig.h с вашей кнопкой, SSID и паролем этот патч не заменяет.
5. Соберите и загрузите с прежними библиотеками: Arduino-ESP32 2.0.17,
   AsyncTCP 3.3.2, ESPAsyncWebServer 3.6.0. ESP32-S3, CPU 240 МГц,
   USB-OTG (TinyUSB), USB CDC On Boot Disabled, Arduino/Events On Core 0.
   Движок по-прежнему закреплён за Core 1. Стирание всей Flash не требуется.
6. Войдите GPIO9, подключитесь к своей точке доступа, откройте http://192.168.4.1
   и обновите страницу. Вверху должна отображаться R4.3.

Файлы для замены:
CalibrationStore.h, EngineSafety.h, EngineeringMode.cpp, EngineeringMode.h,
EngineeringPage.h, RecoilEngine.ino, TuningConfig.h, TuningJson.h, TuningModel.h.
Новый файл: MotionModel.h.

## Интерфейс

Оставлены одна динамическая визуализация, выбор редактируемого CLOSE/LONG,
общая сила основы и шесть ползунков каждого режима:
горизонталь, вертикальная форма, интенсивность шума, начало, тело, хвост.
Изменения отправляются и предпросмотр обновляется во время перетаскивания,
а не только после отпускания ползунка.

Диагностика, гистограммы, таймер вычислений, запись удержаний, отчёты о смещении,
CSV и их HTTP-маршруты удалены из интерфейса и прошивки.
Экспорт/импорт JSON оставлен только для настроек.

## Значение регуляторов

- Сила основы: 0–150 шагов, множитель 0,00–3,00; общая для режимов.
- Горизонталь основы: 0–100%. Меняет только базовое X-движение.
- Вертикальная форма: 0–100%. На 0% — равномерная вертикальная подача;
  на 100% — исходная вертикальная форма и её стартовая обработка.
- Интенсивность шума: 0–200%. 0 выключает шум, 100 — базовый абсолютный уровень,
  200 — удвоенный. Уровень не зависит от силы основы, горизонтали,
  вертикальной формы или масштаба участков.
- Начало / тело / хвост: −100…+100%. Это масштаб смещения основы, не времени:
  −100 выключает основу участка, 0 оставляет базовый масштаб, +100 удваивает.
  Переходы коэффициентов сглажены; внутри полностью выключенного участка
  геометрическая основа равна нулю. Шум остаётся отдельным.

Следствия независимости:
- При горизонтали 0% шум по X остаётся, если его интенсивность выше нуля.
- При силе основы 0 или выключенном участке шум тоже может создавать движение.
- Для полного отключения устройства используется FN → OFF.
- Для строго прямой вертикальной основы задайте горизонталь 0, шум 0,
  вертикальную форму 0 и одинаковые значения трёх участков.
- Разные значения начала/тела/хвоста намеренно задают разные уровни подачи,
  в том числе при вертикальной форме 0. Между ними действует плавный переход.

Новая вертикальная форма применяется после исходной стартовой огибающей,
catch-up и фильтрации: на 0% они не создают подбросов базовой вертикали.
Вертикальный возврат после короткого тапа также ослабляется этой настройкой;
при 0% вертикального возврата нет. При 100% стартовая модель сохраняется.
Равномерность относится к расчётной скорости: USB передаёт целые HID counts,
а дробная часть накапливается. На экране остаётся обычная дискретизация.

Шум имеет отдельный быстрый поток случайных значений, сеяный аппаратным RNG
при начале удержания. Внутреннее сглаживание микрошумa фиксировано на 12 мс.
Привязка шума к силе и усталости удалена. Поэтому прежний процент шума может
ощущаться иначе; после обновления подберите его заново собственным ползунком.

## Визуализация

Начало — сегменты 1–6, тело — 7–18, хвост — 19–30 и его повторения.
Цветные участки используют фактические банки и общие с движком функции
составления движения, шума, фильтра, стартовой огибающей и catch-up.
Показан расчёт одного холодного удержания на 3 секунды при номинальных интервалах.
Метки расположены через 100 мс: по расстоянию между ними видно выравнивание Y.
Оси X/Y имеют отдельные масштабы. Рамка учитывает исходную траекторию, чтобы
автомасштабирование не скрывало уменьшение горизонтали.

Изначально выбран последний использованный паттерн данного режима.
Сохраняются только два номера, без истории перемещений и отчётов.
Номер 0–79 можно менять для просмотра; рабочий выбор паттерна остаётся случайным.
В предпросмотре используется воспроизводимый шум для сравнения настроек.
Реальные случайные значения, зеркалирование, джиттер интервалов, warm-start,
округление USB и обработка ОС могут отличаться. Предпросмотр не является записью
реального движения устройства.

## Хранение и применение

Шесть коэффициентов каждого режима и общая сила переносятся из NVS/JSON схем 2/3.
Новая схема — 4; сохранение остаётся двухслотовым с CRC и проверкой чтением.
Старые расширенные настройки больше не управляют моделью: переходы фиксированы
на 80 мс номинально, микрошум на 12 мс, catch-up ограничен 50% базовой скорости,
плавное охлаждение включено. Они не занимают место в интерфейсе.

Изменения сохраняются автоматически. Дождитесь «Сохранено» перед GPIO9.
Выход по GPIO9 выключает сеть, перезапускает устройство и применяет коэффициенты.
Во время настройки HID приостановлен; в обычном режиме сеть выключена.

## Проверки

- Сборка ESP32-S3: статическая RAM 94 548 байт, Flash 852 633 байта.
  По сравнению с R4.2 освобождено 33 284 байта статической RAM.
  Это данные компоновки, не замер свободного heap во время работы Wi-Fi.
- Проверено отсутствие символов записи/профилирования/диагностики в ELF.
- 160 полных модельных удержаний (80 паттернов x 2 режима): при H=0,
  вертикальной форме=0, шуме=0 и равных участках выход одинаков для всех
  паттернов данного режима, включая случайные интервалы и первый повтор хвоста.
- 160 предпросмотров: реакция горизонтали, равномерный Y, границы участков.
- Независимость и ограниченность шума, промежуточная вертикальная форма,
  плавные коэффициенты участков и нулевая основа без подавления шума.
- Миграция NVS и JSON 2/3 → 4, CRC, два слота и восстановление при ошибках.
- Старты с зажатым микриком, OFF, USB loss/busy/rejects, вход в инженерный режим.
- Семь ползунков, очередь AJAX/CAS, обновление при перетаскивании, цветные участки,
  временные метки, устаревшие ответы, масштаб, импорт/экспорт настроек.
- Проверка ранних прототипов Arduino IDE 1.8.19.

Физические испытания новой версии на ESP32-S3 в этой среде не проводились.
Для первого теста используйте рабочую ненулевую силу, H=0, вертикальную форму=0,
шум=0 и начало/тело/хвост=0. Затем отдельно добавляйте форму, горизонталь и шум.
