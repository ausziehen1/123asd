Пользователям передавайте **один EXE из `clients`** полного архива. Он сам размещает DLL в локальном кэше. Сервер и SQLite работают централизованно. Для встроенного бланка один раз нужен WebView2 Runtime Evergreen x64.

Новые сохранения проходят через FIFO-очередь: разные ячейки объединяются, одинаковые меняются последним обработанным запросом. Изменения автоматически поступают в открытые окна. Для пересекающихся структурных изменений применяется последнее состояние листа, предыдущие версии остаются в истории.
