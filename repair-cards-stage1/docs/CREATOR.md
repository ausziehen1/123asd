# Креатор — регистрация партий

Это отдельная Windows-программа на C++. Qt и дополнительные интерфейсные библиотеки не требуются.
Здесь описаны регистрация партий и список карточек. Обновление 0.4, QR и BarTender — [QR_PRINT_READER.md](QR_PRINT_READER.md); редактирование бланка — [EDITOR.md](EDITOR.md).

## 1. Обновить существующий проект

1. Остановите сервер и Креатор.
2. Скопируйте папку `data` проекта в отдельную папку для резервной копии.
3. Распакуйте новый архив во временное место. В нем находится папка `RepairCards-stage1`.
4. Скопируйте **содержимое** этой папки в вашу существующую папку проекта, где лежат `CMakeLists.txt` и `data`, с заменой исходников.
5. В CLion выполните **Reload CMake Project**.

Архив не содержит `data`, рабочих баз или каталогов сборки. Есть готовые EXE в `ready-windows`. Сервер обновляет схему SQLite, сохраняя карточки. Перед обновлением следуйте `QR_PRINT_READER.md`.
Файл `config.example.json` включен в архив; если меняли его вручную, сохраните свои настройки перед заменой.
Название папки `RepairCards-stage1` оставлено прежним, чтобы обновлять существующий проект.

## 2. Собрать и запустить сервер

Запустите прежнюю конфигурацию **repair_server** с прежней рабочей папкой и аргументами.
Откройте http://127.0.0.1:8080 и убедитесь, что пять существующих карточек видны.
Текущая версия сервера — 0.4.0.

## 3. Собрать и запустить Креатор

1. Оставьте `repair_server` работающим.
2. В верхнем списке целей CLion выберите **repair_creator**.
3. Соберите эту цель и нажмите **Run**.
4. Для `repair_creator` аргументы программы не нужны.

Появится отдельное окно **«Креатор — Карточки ремонта 0.4»**.

## 4. Проверить существующие карточки

1. Адрес сервера оставьте `http://127.0.0.1:8080`.
2. Нажмите **«Подключить»**.
3. В списке должны появиться существующие карточки. На другом ПК укажите сетевой адрес сервера вместо 127.0.0.1.
4. Выберите тип **«Ноутбук 16.5»**. Список отфильтруется, а в поле начального ID появится предложенный сервером следующий номер — `V00006`, если зарегистрирована только первая партия.
5. Выделите запись и нажмите **«Редактировать»** либо дважды нажмите на строку. Откроется редактор в браузере.

Креатор читает данные через сервер. У него нет собственной копии базы; пять существующих карточек не нужно регистрировать повторно.

## 5. Проверить регистрацию из окна

Для небольшого теста можно создать следующую партию из двух карточек:

- Тип: **Ноутбук 16.5**.
- Начальный ID: **V00006**.
- Количество: **2**.

Нажмите **«Проверить диапазон»**: будет показано `V00006 — V00007`, без создания записей.
Кнопка **«Создать партию»** также сначала получает диапазон, затем показывает подтверждение.
После подтверждения появится сообщение о сохранении, а предложенный следующий ID сменится на `V00008`.

Проверяйте реальные предложенные номера: если ранее уже создавали другие партии, значения будут отличаться.

## Добавить новый тип

Нажмите **«+»** рядом со списком типов, введите название и нажмите **«Добавить»**.
Новый тип появится в выпадающем списке. Для его первой партии начальный ID задается вручную.
Точное совпадение имени возвращает уже существующий тип.

## Поведение при ошибках

- Во время сетевого запроса действия регистрации временно недоступны; само окно продолжает отвечать.
- При отсутствии ответа на регистрацию программа сообщает, что партия могла сохраниться. Перед повтором обновите список и проверьте записи.
- Автоматической повторной регистрации нет.
- «Обновить» получает актуальные типы, подсказки ID и первую страницу выбранного типа. Введенный вручную начальный ID сохраняется при обновлении.
- Постранично показывается по 100 карточек, предусмотрены «Назад» и «Следующие 100».
- Разрешено ручное изменение начального ID и совпадение ID продукции у разных записей.

## Проверки

- `core_tests` — проверка SQLite, партий и сохранения.
- `client_tests` — проверка общения Креатора с HTTP API, фильтрации, диапазонов и ошибок.
- Windows EXE успешно собран кросс-компилятором LLVM-MinGW.
- Запуск окна на Windows 10 / MinGW64 нужно проверить на вашем ПК.

Для этого шага не нужны установка Qt, новая база или повторный запуск `03_demo.cmd`.
